# AUTOKEYS SAT V4.1 INTEGRADA

Novedades integradas dentro de cada OT:
- Historial por matrícula / VIN / teléfono en la propia orden.
- Estados profesionales con colores.
- Presupuesto dentro de la OT.
- Presupuesto imprimible / PDF.
- Adjuntos manuales: fotos, EEPROM, FLASH, IMMO, diagnósticos.
- Caso técnico interno dentro de la OT.
- Acceso a documentos: Presupuesto, Copia cliente y Garantía GAR-001.

Pasos:
1. Ejecuta `supabase_schema.sql` en Supabase SQL Editor.
2. Abre `index.html`.
3. Busca `PEGA_AQUI_TU_CLAVE_LEGACY_O_PUBLISHABLE`.
4. Sustitúyelo por tu clave Supabase si no está puesta.
5. Sube los 3 archivos al repo limpio.
6. Vercel desplegará automáticamente.
